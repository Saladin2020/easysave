# Easy Suite brand assets

Generated by the Easy Suite brand scripts (`easy-suite-brand/save_v2.py` on top of `suite12_v2.py`). Same frame,
palette and fonts across all thirteen tools; only the icon and accent colour change. Easy Save uses silver `#9fb4cc`
and a floppy disk with a speech bubble (saves + strings); its banner and social art are a save-select screen with
the same slot labels in Thai, English and Malay (one slot migrated from v1, one autosave).

| File | Use |
|---|---|
| `banner-save.png` (1280×320) | README header |
| `social-save.png` (1280×640) | GitHub social preview: Settings → General → Social preview → Upload |
| `logo-save.png` (240×240), `logo-save-48.png`, `logo-*-96.png` | Tool logos; the `-96` set is used by the suite table |

Fonts in the art: Press Start 2P and Kanit (both SIL OFL 1.1). v2 style: subtle green accent and a light
8-point star (girih) pattern on the teak, cream and gold palette.
